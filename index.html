Encryption and multi-hop routing

Write a message and watch it get converted to binary, assigned a session code, and see that code change at every server it passes through before reaching the destination.

01001000011011110110110001100001
This is a conceptual demo, not real security software. Converting text to binary isn't encryption — it's reversible without any key, and just represents the text as bytes. The session code and its rotation at each node illustrate the idea of layered routing (similar in spirit to Tor), but here they're generated with Math.random() in the browser, with no real cryptography involved. Don't use this to protect sensitive information.
